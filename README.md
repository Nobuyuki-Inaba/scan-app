# 在庫スキャンアプリ

店頭のスマートフォン（iPhone SE2 等）でJANバーコードを連続スキャンし、CSV の `category` ごとにグループ表示する在庫確認ツールです。

```
┌──────────────────────────┐
│ 50,000件 | 05/25 10:30 [CSV取得][⚙] │ ← sticky header（⚙で設定・DBクリア）
├──────────────────────────┤
│   ┌──────────────────┐   │
│   │ ┌──────────────┐ │   │ ← カメラ映像と読み取り枠
│   │ └──────────────┘ │   │   （停止前は中央に[▶ 開始]）
│   │[■ 停止]     [⌨] │   │ ← ⌨ でJAN入力欄を表示
│   └──────────────────┘   │
├──────────────────────────┤
│ スキャン済: 3件 [全て閉じる][CLR] │
├──────────────────────────┤
│ ▼ 横浜へ移動 (2件)        │ ← category
│ ✓ ├ 4901234567894    ×   │ ← JAN
│   │  ボールペン 黒       │ ← sku_name
│   │  棚A-3               │ ← description
│ ✓ └ 4006381333931    ×   │
│      消しゴム            │
│ ▼ 残置 (1件)             │
│ ✓ └ 4902102072618    ×   │
│      ノート A5           │
└──────────────────────────┘
```

## セットアップ

### 1. 公開（Cloudflare Workers）

```bash
npm install
npx wrangler login   # 初回のみ
npm run deploy       # テストを通してから public/ を公開
```

公開URL: `https://scan-app.garage-hobby.workers.dev`

手元の iPhone で確認するときは `npm run dev:lan`（同じ LAN で `https://192.168.0.13:8787`）。

### 2. CSVフォーマット

```csv
JAN,sku_name,category,description
4901234567894,ボールペン 黒,横浜へ移動,棚A-3
4006381333931,"消しゴム（大）, 白",残置,棚B-1
```

#### 列

| 列名 | 必須 | 内容 | 画面での使われ方 |
|------|:---:|------|------|
| `JAN` | ◯ | JANコード（EAN-13 / EAN-8 / UPC-A） | 照合のキー |
| `sku_name` | | 商品名 | 結果の各行に表示 |
| `category` | | 区分（移動先・処理区分など） | 結果をこの値でグループ分け。空なら「（カテゴリなし）」 |
| `description` | | 補足 | 商品名の下に小さく表示 |

- **列名の書き方**: 大文字小文字、`_`・`-`・空白の違いは区別しません（`sku_name` / `sku-name` / `SKU Name` はどれも同じ）。次の日本語名も使えます。

  | 列 | 使える列名 |
  |----|-----------|
  | JAN | `JAN`, `JANコード`, `JAN Code` |
  | 商品名 | `sku_name`, `name`, `商品名`, `品名` |
  | 区分 | `category`, `カテゴリ`, `カテゴリー`, `分類` |
  | 補足 | `description`, `説明`, `備考` |

- **列の順番**は自由です。上の表にない列は無視します。
- **ヘッダー行なし**でも読めます。1行目の先頭セルが数字なら、ヘッダーなしとみなして列順（JAN, 商品名, 区分, 補足）で読みます。
- 商品名にカンマや改行を含めるときは、`"…"` で囲みます（Excel・Google スプレッドシートが保存時に自動で付けます）。

#### 文字コード

- **UTF-8**（BOM の有無は問いません）と **Shift_JIS** を自動判定します。
- Google スプレッドシートの CSV ダウンロード、Excel の「CSV UTF-8」「CSV（コンマ区切り）」のどれで保存しても、日本語の商品名は化けません。

#### JAN の扱い

- **12桁**は先頭に `0` を付けて13桁として扱います（UPC-A。Excel で先頭の0が落ちたものもこれで一致します）。
- **同じ JAN が複数行ある**ときは、下の行の内容を使います。
- JAN が空の行は読み飛ばします。
- Excel で JAN が `4.9E+12` のような**指数表記**になった行は、桁が失われているため読み込めません（件数を警告表示します）。Excel で JAN 列を「文字列」にして保存し直してください。

#### 読み込み方法

- **端末から選ぶ**: [CSV取得] → [端末からファイルを選択]。iPhone では「ファイル」アプリから iCloud Drive や Google ドライブ上の CSV も選べます。
- **URL から読む**: Google スプレッドシートの場合は「ファイル → 共有 → ウェブに公開」で形式を「CSV」にした URL を使います。Google ドライブの共有リンク（`…/view`）は CSV ではなく Web ページが返るため使えません。
- 読み込むたびにデータは**全件入れ替え**になります（追記ではありません）。

## 使い方

### データ読み込み（日次）

1. CSVファイルをHTTPS でアクセス可能なURL に配置する（Google Sheets の公開リンク等）
2. アプリの **[CSV取得]** ボタンをタップ
3. URLを入力して **[読み込む]** をタップ
4. 「〇〇件の読み込み完了」と表示されれば完了（次回以降は同URLが自動補完される）

### バーコードスキャン

1. **[▶ 開始]** をタップ → カメラ起動（初回はアクセス許可が必要）
2. バーコードを白枠に合わせ、10〜20cm 離してかざす → 自動読み取り
3. 結果がカテゴリごとにグループ表示される
4. 同じJANを再スキャンしても重複追加されない（緑フラッシュのみ）
5. データに存在しないJANは赤フラッシュ＋「不明」グループに表示
6. 新しい版を公開すると、次回起動時に「新しいバージョンがあります」と表示される。**[更新]** で切り替え
7. **[CLR]** でスキャン結果をリセット

### ホーム画面への追加（推奨）

Safari の共有ボタン →「ホーム画面に追加」でランチャー登録すると、フルスクリーンで起動できます。

## 技術仕様

### 使用ライブラリ（public/vendor/ に自己ホスト）

| ライブラリ | バージョン | 用途 |
|-----------|-----------|------|
| [zxing-wasm](https://github.com/Sec-ant/zxing-wasm) | 3.1.4 | ZXing C++ の WebAssembly 版。映像を元解像度で切り出してデコード |
| [PapaParse](https://www.papaparse.com/) | 5.7.0 | CSVパース（チャンク単位） |

### データストレージ

- **IndexedDB** にCSVデータを保存（`scan_app_db` / `products` ストア）
- JAN をキーとした直引きで検索時間 2〜10ms
- 50,000行 ≒ 10〜15MB（iOS SafariのIndexedDB上限は〜1GB）
- 最終同期日時・件数は `localStorage` に保存

### iOS Safari 対応ポイント

- `getUserMedia()` はユーザージェスチャーから同期的に呼び出し
- `overscroll-behavior: none` でプルトゥリフレッシュを無効化
- `visibilitychange` でバックグラウンド遷移時にカメラを自動停止
- `env(safe-area-inset-*)` でノッチ・ホームバー領域を確保
- プライベートブラウズ（IndexedDB 使用不可）を検知して案内表示
