# 在庫スキャンアプリ

店頭のスマートフォン（iPhone SE2 等）でJANバーコードを連続スキャンし、備考単位でグループ表示する在庫確認ツールです。

```
┌──────────────────────────┐
│ 在庫スキャン    [同期]    │ ← sticky header
│ 50,000件 | 05/25         │
├──────────────────────────┤
│   ┌──────────────────┐   │
│   │   カメラビュー    │   │ ← カメラ映像
│   └──────────────────┘   │
│   [▶ 開始]    [■ 停止]   │
├──────────────────────────┤
│   スキャン済: 3件  [CLR]  │
├──────────────────────────┤
│ ▼ 横浜へ移動 (2件)        │
│   ├ 4901234567890        │
│   │   ラック:A  棚:3     │
│   └ 4901234567891        │
│       ラック:B  棚:1     │
│ ▼ 残置 (1件)             │
│   └ 4901234567892        │
│       ラック:C  棚:2     │
└──────────────────────────┘
```

## セットアップ

### 1. Apacheへの配置

`scan_app/` フォルダごとApacheのドキュメントルート下に配置します。

```
/var/www/html/
└── scan_app/
    ├── index.html
    ├── css/
    ├── js/
    └── data/
        └── products.csv
```

アクセスURL: `https://[サーバーのドメインまたはIP]/scan_app/`

> ApacheがまだHTTPS未対応の場合は、Let's Encrypt（certbot）で無料のTLS証明書を取得してください。

### 2. CSVフォーマット

Google Sheetsから「CSV形式でダウンロード」したファイルをそのまま使用できます。

**必須列（順不同、ヘッダー名が一致すること）:**

| 列名 | 内容 | 例 |
|------|------|----|
| `JAN` | JANコード（EAN-13） | `4901234567890` |
| `ラック` | ラック番号 | `A` |
| `棚番号` | 棚番号 | `3` |
| `備考` | 移動先・処理区分など | `横浜へ移動` |

```csv
JAN,ラック,棚番号,備考
4901234567890,A,3,横浜へ移動
4901234567891,B,1,残置
4901234567892,C,2,横浜へ移動
```

## 使い方

### データ同期（日次）

1. Google Sheets から CSV をダウンロード
2. FTP/SFTP等で `data/products.csv` を上書きアップロード
3. iPhone Safari でアプリを開き **[同期]** をタップ
4. 「〇〇件の同期完了」と表示されれば完了（次回以降は同期なしでもスキャン可能）

### バーコードスキャン

1. **[▶ 開始]** をタップ → カメラ起動（初回はアクセス許可が必要）
2. カメラにJANバーコードをかざす → 自動読み取り
3. 結果が備考ごとにグループ表示される
4. 同じJANを再スキャンしても重複追加されない（緑フラッシュのみ）
5. データに存在しないJANは赤フラッシュ＋「データなし」表示
6. **[CLR]** でスキャン結果をリセット

### ホーム画面への追加（推奨）

Safari の共有ボタン →「ホーム画面に追加」でランチャー登録すると、フルスクリーンで起動できます。

## 技術仕様

### 使用ライブラリ（CDN）

| ライブラリ | バージョン | 用途 |
|-----------|-----------|------|
| [html5-qrcode](https://github.com/mebjas/html5-qrcode) | 2.3.8 | ZXing ベースのカメラスキャン |
| [PapaParse](https://www.papaparse.com/) | 5.4.1 | CSVストリーミングパース |

### データストレージ

- **IndexedDB** にCSVデータを保存（`scan_app_db` / `products` ストア）
- JAN をキーとした直引きで検索時間 2〜10ms
- 50,000行 ≒ 10〜15MB（iOS SafariのIndexedDB上限は〜1GB）
- 最終同期日時・件数は `localStorage` に保存

### iOS Safari 対応ポイント

- `getUserMedia()` はユーザージェスチャーから同期的に呼び出し
- `overscroll-behavior: none` でプルトゥリフレッシュを無効化
- `visibilitychange` でバックグラウンド遷移時にカメラを自動停止
- `env(safe-area-inset-*)` でノッチ・ホームバー領域を確保
- プライベートブラウズ（IndexedDB 使用不可）を検知して案内表示
